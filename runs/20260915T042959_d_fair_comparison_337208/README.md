# ⚠️ 本目录的保证金参数是错的（k=0.5，应为 k=1/L=1.0）—— 请用修正后重跑的那份

**日期**：2026-09-15
**脚本**：`scripts/d_fair_comparison.py`（当时的版本）

## 哪里错了

脚本当时把初始保证金率**硬编码为 0.5**：

```python
margin_cfg = MarginConfig(initial_margin_ratio=0.5, ...)
```

强平阈值只由 `(k, m)` 决定、**与杠杆无关**（`|u|` 在推导里约掉）：

```
p/p0 = (1 − k) / (1 − m)        k=0.5, m=0.1  ⇒  −44.44%
```

所以这个组合给一个 **`max_gross = 1.0`（1x、无借款）** 的仓位强加了一条
**−44.4% 的隐形停损**，而这个停损与脚本声明的杠杆毫无关系。
更糟的是 `HedgeEnsemble` 的 band 语义**开环**：强制平仓后不会再发目标，
于是被"停损"的静态规则**永不返场**。

修法：`MarginConfig.for_leverage(EXPOSURE)` 推出 `k = 1/EXPOSURE = 1.0` ⇒ 阈值 0，
1x 无借款下**不该有任何强平**。见 `src/sim/margin.py` 的模块 docstring。

## 哪些数字受影响

| 指标 | 本目录（k=0.5，错） | 影响 |
|---|---|---|
| 等权再平衡 | 490,657 | 含假强平通道 |
| 学习体 | 200,595 | 含假强平通道 |

**方向性**：假强平通道**只打击会调仓的候选**（静态持有一旦被强平也永不返场，
但它本来就不调仓，通道很少触发）。学习体的平均 gross 只有 0.65 且频繁调仓，
是被这个通道打击最重的一类 —— 所以本目录**低估了学习体**、相对**高估了被动组合**。

按 `FRAMEWORK_AUDIT.md` 的量化：关掉假强平后学习体 200,595 → 325,268（**+62%**），
被动组合只 +3%。**所以本目录支撑的"学习体输 ↔ 倍"这个结论不成立。**

## 结论

**本目录只应作为"错误参数的证据留存"，不应被任何结论引用。**
修正后的重跑见 `runs/` 下同日期的另一份 `d_fair_comparison`（`derived_from: leverage=1.0`）。
