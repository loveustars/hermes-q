## 确定性

同日两次独立运行（#2 与 #3）的 `all_configs.csv` **排除 `seconds` 计时列后逐值相同**，
即本脚本是确定性的（Hedge 无 RNG，延迟抖动默认关闭）。
所以重跑不会给出不同数字，只有计时列会变。
